# face 콕 — 기능 명세

정리 기준일: 2026-09-03

전체 기능 범위를 다룬다. 실무 코딩 분담(담당자A/B)과는 별개로, 이 문서는 팀 전체가 보는 기준 문서다.

## 1. 로그인 / 회원가입

| 항목 | 내용 |
| --- | --- |
| 가입 방식 | 최초 가입 시 이메일 인증코드 확인 후 8자 이상 비밀번호 설정 |
| 참가자 로그인 | 이메일 + 비밀번호 (BCrypt 해시 검증) |
| 필수 동의 | 서비스 이용약관, 개인정보처리방침 |
| 로그인 유지 | 서명된 세션 쿠키 (HMAC), 7일 유효 |
| 관리자 로그인 | 별도 아이디/비밀번호 방식, 참가자 로그인과 분리된 세션 |
| 정지 계정 | 로그인 시도 시 즉시 차단, 이미 로그인된 세션도 요청마다 상태 재확인 후 정지 감지되면 강제 로그아웃 |

기존 `purpose=login` 인증코드 발급과 OTP 로그인 API는 호환성을 위해 당분간
유지한다. 프론트 전환과 기존 계정의 비밀번호 설정 정책이 확정된 뒤 제거 여부를
별도로 판단한다.

## 2. 프로필

| 항목 | 필수/선택 | 비고 |
| --- | --- | --- |
| 닉네임, 성별, 나이, MBTI, 취미, 혈액형 | 필수 | 최초 등록 후 수정 불가 |
| 학과, 학년, 자기소개, 사진, 이상형 | 선택 | 마이페이지에서 언제든 수정 가능 |
| 기본 이미지 | — | 사진 미등록 시 기본 이미지 표시 |
| 프로필 조회 | — | 다른 참가자 프로필 상세 조회 가능 |
| 현재 활동 중 표시 | — | 최근 활동 시각 기준 |

## 3. 콕찔러보기 / 매칭

| 항목 | 내용 |
| --- | --- |
| 참가자 목록 | 본인 제외, 메인 화면에서 조회 |
| 콕 보내기 | 하루 3회 제한 (KST 자정 기준 초기화), 행사 전체 총량 제한 별도 |
| 중복/취소 | 같은 상대에게 중복 발송 불가, 대기중(맞콕 전) 상태면 취소 가능 |
| 취소 규칙 | 취소해도 오늘 사용 횟수는 원복되지 않음, 취소해도 같은 상대에게 재전송 불가 |
| 자동 만료 | 없음. 상대가 맞콕하거나 보낸 사람이 취소할 때까지 유지 |
| 상호 매칭 | 서로 콕을 보내면 즉시 매칭 성사, 이후 시간 제한 없음 |
| 매칭 후 데이터 | 날짜가 바뀌어도 매칭·채팅 데이터 유지 |

## 4. 채팅

| 항목 | 내용 |
| --- | --- |
| 채팅방 생성 | 매칭 성사 시 자동 생성 (별도 테이블 없이 `match_info` = 채팅방 단위) |
| 메시지 형식 | 텍스트만, 사진/영상 미지원 |
| 운영시간 | 09:00~18:00에만 전송 가능 (조회는 시간 제한 없음) |
| 실시간 전달 | WebSocket(STOMP), 서버 2대 간 Redis Pub/Sub으로 중계 |
| 전송 안정성 | ACK 기반, `client_message_id`로 재전송 시 중복 방지 |
| 데이터 보존 | 행사 마지막 날까지 유지, 날짜 변경돼도 안 지워짐 |

## 5. 미션

| 항목 | 내용 |
| --- | --- |
| 구성 | STEP 1 → 2 → 3, 순차 공개 |
| 안내 위치 | 채팅 화면 상단에 미션 카드로 표시 |
| 완료 처리 | 참가자가 부스에서 실물로 미션 수행 → 관리자가 육안 확인 후 "완료" 버튼 클릭 |
| 다음 단계 공개 | 관리자가 완료 처리하면 참가자 채팅창에 다음 STEP 자동 공개 |
| 선물 | STEP별 제공, STEP3까지 완료 시 최종 선물 (실물 지급, 시스템 범위 아님) |
| 미션 내용 | 별도 리스트 전달받지 않음 — STEP 완료 처리 기능만 구현, 내용은 운영진이 현장 판단 |

## 6. 신고 / 제재

| 항목 | 내용 |
| --- | --- |
| 신고 대상 | 다른 참가자 |
| 신고 내용 | 사유(카테고리) + 상세 사유 |
| 처리 방식 | 경고 단계 없이, 관리자 판단으로 즉시 영구정지 또는 종결 |
| 영구정지 효과 | 로그인 제한, 콕 발송 제한, 신규 매칭 제한, 신규 채팅 제한 |
| 관리자 확인 자료 | 신고 건에 연결된 채팅 열람 가능 |

## 7. 관리자

| 항목 | 내용 |
| --- | --- |
| 대시보드 통계 | 현재 접속자 수, 전체 가입자 수, 매칭 수, 콕 사용량(당일/전체), 신고 대기 건수, 미션 완료 현황 |
| 미션 관리 | 커플별 진행 단계 확인, STEP 완료 처리 |
| 신고 관리 | 목록 조회, 상세(관련 채팅 포함), 처리(영구정지/종결) |
| 관리자 알림 | 별도 백그라운드 푸시 없음 — 대시보드 접속 중 WebSocket 실시간 반영으로 충분 (부스에 상주한다고 가정) |

## 8. 알림 (웹 푸시) — 참가자 전용

| 이벤트 | 알림 대상 |
| --- | --- |
| 콕 받음 | 콕 받은 사람 |
| 매칭 성사 | 매칭된 두 사람 |
| 메시지 도착 (WebSocket 미연결 시) | 메시지 수신자 |

- 앱 사용 중(WebSocket 연결 상태)이면 인앱 배너로 대체, 백그라운드 푸시는 미연결 시에만 발송
- 아이폰은 "홈 화면에 추가(PWA 설치)" 필수, 안드로이드/PC는 브라우저 알림 권한만으로 동작
